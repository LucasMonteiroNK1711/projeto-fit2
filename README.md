## 📖 Sobre o projeto

O **Projeto Fit2** é uma aplicação desenvolvida com foco em aprendizado e evolução prática no desenvolvimento fullstack.

A proposta do projeto é simular um sistema voltado para o universo fitness, permitindo o gerenciamento de informações relevantes como treinos, usuários ou acompanhamento físico (dependendo da evolução do projeto).

Este projeto serve como laboratório para aplicar conceitos reais de desenvolvimento, organização de código e boas práticas.

---

## 🧠 Objetivos

- Praticar desenvolvimento fullstack
- Melhorar organização de código
- Trabalhar com integração entre frontend e backend
- Evoluir lógica de programação
- Criar algo próximo de um sistema real
